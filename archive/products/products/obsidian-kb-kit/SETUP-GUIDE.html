Obsidian Knowledge Base

Your brain,
organized

A pre-built knowledge base for Obsidian. Download it, open it, and start organizing your life in 5 minutes.

// setup guide

Setup

01

Install Obsidian

Download from obsidian.md. Free, works on Mac, Windows, Linux, iOS, Android.

02

Open the Vault

In Obsidian, click "Open folder as vault" and select the vault folder from this kit.

03

Enable Plugins

Go to Settings → Core plugins. Enable:

  • Daily notes
  • Templates
  • Backlinks
  • Graph view

04

Configure Daily Notes

Set "New file location" to 01-Journal and "Template file location" to Templates/Daily Note.

Structure

05

Understand Your Vault

Your vault uses a simplified PARA structure — Projects, Areas, Resources, Archive — plus an Inbox for quick capture and a Journal for daily notes.

Folder Structure
vault/ ├── 00-Inbox ← Quick capture, unprocessed ├── 01-Journal ← Daily notes (YYYY-MM-DD.md) ├── 02-Projects ← Active projects with goals ├── 03-Areas ← Ongoing life areas ├── 04-Resources ← Reference material ├── 05-Archive ← Completed/inactive items ├── Templates ← Note templates └── Attachments ← Images, PDFs, files
