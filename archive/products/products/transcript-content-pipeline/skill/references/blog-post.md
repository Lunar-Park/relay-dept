# Reference: Blog Post

Turn the transcript into a standalone, well-structured article that reads like it was written for the page — not transcribed.

## Length

- **Standard:** 800–1,400 words
- **Long-form:** 1,500–2,500 words (only if the transcript has enough substance)
- Never pad. A tight 900-word post beats a bloated 2,000-word one.

## Structure

1. **Headline** — Offer 3 options. Specific and benefit- or curiosity-driven. Avoid "My Thoughts on X."
2. **Hook (1-2 short paragraphs)** — Lead with the most surprising idea, a vivid moment, or the core tension. No "In this episode we discussed…"
3. **Body** — 3-6 sections with descriptive H2 headers. Each section = one key idea from the transcript, developed into prose with:
   - A clear point
   - Supporting detail/example from the recording
   - A pulled quote where it earns its place
4. **Pull quotes** — Format 2-3 strong verbatim lines as blockquotes (`>`).
5. **Takeaway / conclusion** — One tight section that lands the thesis and tells the reader what to do or think next.
6. **Optional CTA** — Link to the full recording, newsletter, etc. Use a placeholder if no link given.

## Voice

- Active, direct, confident. Short paragraphs (2-4 sentences).
- Convert spoken hedging ("um, I think maybe sort of") into clean assertions.
- Keep the speaker's distinctive phrasing and personality where it's good.

## Source timecodes

Tag each pulled blockquote with its source timecode, e.g. `> "..." — [01:10]`. End the post with a small **Source timecodes** section mapping each H2 section and quote to its origin time in the recording, so the editor can find the moment. Don't invent timecodes; omit this if the transcript has none.

## Front matter (optional)

If the user publishes via a static site, offer YAML front matter:

```yaml
---
title: "..."
date: [DATE]
description: "..."
tags: []
---
```

## Don't

- Don't open with a summary of the format ("This blog post will cover…").
- Don't keep filler, false starts, or tangents from the transcript.
- Don't invent statistics, sources, or quotes.
