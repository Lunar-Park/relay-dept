# Reference: Show Notes

Produce episode show notes for a podcast or video — the scannable companion that lives in the description or on the episode page. Timestamps are the killer feature; preserve them if the transcript has them.

## Structure

1. **Episode title** — Offer 2-3 options if not given.
2. **One-line description** — The episode in a single compelling sentence (for previews/SEO).
3. **Summary paragraph** — 3-5 sentences on what the episode covers and why it's worth a listen.
4. **Timestamps / chapters** — The core deliverable. Format:
   ```
   (00:00) Intro
   (02:14) Why X matters
   (08:41) The turning point
   (15:30) Practical takeaways
   ```
   - Use the transcript's timestamps. If none exist, **omit this section** and tell the user timestamps weren't available (don't invent them).
   - One line per distinct segment. Keep labels short and curiosity-driven.
5. **Key takeaways** — 3-6 bullet points of the most useful insights.
6. **Notable quotes** — 1-3 verbatim pull quotes with speaker attribution.
7. **Links & resources mentioned** — Anything referenced in the recording. Use `[PLACEHOLDER]` for links you can't verify, and list what the user needs to add.
8. **Guest bio** (if applicable) — Short bio. Use `[GUEST TITLE / BIO]` placeholders rather than inventing credentials.

## Voice

- Informative and scannable. This is reference material, not prose.
- Bullets and short lines over paragraphs (except the summary).

## Don't

- Don't invent timestamps, links, episode numbers, or guest credentials.
- Don't write it as a narrative essay — it should scan in 10 seconds.
