# Reference: Social Thread

Turn the transcript into a multi-post thread for X/Twitter or LinkedIn. Confirm the platform first — they have different conventions.

## Platform differences

| | X / Twitter | LinkedIn |
|---|---|---|
| Post length | ≤ 280 chars/post | Longer posts OK; one "post" can be a paragraph |
| Thread length | 5–12 posts | 1 long post OR a 4–7 part series |
| Tone | Punchy, lowercase-friendly, fast | Professional, a bit more context |
| Hooks | Bold claim / number / curiosity gap | Story-driven opener works well |
| Hashtags | 0–2, sparingly | 3–5 at the end is normal |

## Structure (X/Twitter thread)

1. **Hook post (the most important one)** — Stop the scroll. Use a bold claim, a surprising number, a contrarian take, or a curiosity gap. Tease the payoff. No "🧵👇" required but fine.
2. **Body posts** — One idea per post. Make each post able to stand alone *and* pull the reader to the next. Use line breaks for readability.
3. **Proof posts** — Drop 1-2 verbatim quotes from the speaker for credibility.
4. **Closer** — Summarize the through-line + a CTA (follow, watch the full thing, reply). Link with a placeholder if none given.

## Structure (LinkedIn)

- Open with a 1-line hook on its own line (it's what shows above "…see more").
- Short paragraphs, generous line breaks.
- End with a question to drive comments + 3-5 hashtags.

## Formatting rules

- Number multi-post X threads as `1/`, `2/` … or `🧵 1/n` if the user wants counts.
- Keep each X post under 280 characters — **actually check the count**.
- No walls of text. White space is a feature.
- Emojis: light touch, only if they fit the user's brand.

## Source timecodes

For each post built from a specific moment, note the source timecode after it (e.g. `[01:10]`) — invaluable for cutting a matching video clip per post. Keep these in the working draft; the user can strip them before publishing. Add a **Source timecodes** appendix at the end. Skip if the transcript has no timestamps.

## Output format

Deliver as a numbered list, each post clearly separated, with a character count noted for X posts:

```
1/ [hook post]  (243 chars)

2/ [next post]  (198 chars)
...
```

## Don't

- Don't fabricate engagement bait stats.
- Don't turn every line of the transcript into a post — curate ruthlessly.
- Don't bury the best idea in post 7. Lead with it.
