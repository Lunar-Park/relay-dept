Setup — 4 steps
01

Unzip this package

You should see the setup guide you're reading, the examples/ folder, and the skill file: transcript-content-pipeline-skill.zip. Leave that inner zip zipped — you'll hand it to Claude as-is.

02

Upload the skill to Claude

In Claude (Cowork, desktop, or web), open Settings → Capabilities → Skills and choose Upload skill. Select transcript-content-pipeline-skill.zip.

  • Enable code execution in that workspace so the transcript cleaner and timecode exporter can run.
03

Build your brand profile (once)

Upload a few real brand docs — a style guide, a couple of published posts, your about page — then say:

Use the transcript-content-pipeline skill to
build our brand profile from these docs.

Review the generated brand-profile.md, tweak anything, and save it — it's the source of truth for every output. Re-attach it in future sessions.

04

Turn a recording into content

Upload or paste a transcript (with timestamps if you want the editor export), then ask for what you need:

Using our brand profile, turn this transcript
into a blog post and an X thread, with editor
timecode files. Frame rate is 30.

New to it? Try the included examples/sample-transcript.txt first.

Editor handoff

Files that drop straight into your timeline

As Claude picks quotes and segments, it records their source timecodes and generates files you can import — so you jump to the moment instead of scrubbing.

FileEditorWhat it does
edit.fcpxmlResolve, Final CutTimeline markers at each key moment
edit.xmlPremiere ProSequence markers (FCP7 XML) — File → Import
edit.edlPremiere + ResolveAn assembly of the selected clips (selects)
edit.csvSpreadsheet / ResolvePlain reference / marker import

Premiere tip: import edit.xml (File → Import). It creates a sequence with markers — paste them onto an adjustment layer to drop them into your working timeline.

Good to know

Timecodes need timestamps

The editor export only works if your transcript has timestamps. Most tools export them; .vtt/.srt caption files work great and the skill cleans them automatically.

Set your frame rate

Tell Claude the footage frame rate (24, 25, 29.97, 30, 60…). It defaults to 30; the wrong rate makes timecodes drift.

It won't make things up

Every quote and stat traces back to the transcript. Missing details (dates, links, titles) come back as placeholders for you to fill.

Brand first, always

If no brand profile is loaded, the skill asks for your brand docs before writing — so you never get generic, off-voice output.
