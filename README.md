# Relay Dept

Working repository for Relay Department Productions: concept-to-delivery video production and physical production. Relay produces under agency paper when the agency owns the client relationship, and directly for its own clients.

This repo holds what has to be exact and reusable: brand tokens, the paper stylesheet, print templates for the documents Relay issues, and eventually the production-focused site. The engagement rules, the template prose, and the client records live in the Lunar Park knowledge base and are pointed to from here. Binder, the production-office app, is its own repository.

## Layout

| Folder | What is in it |
|---|---|
| `brand/` | Locked tokens as CSS and JSON, the wordmark rule, font notes |
| `templates/` | `print/` is the Relay paper stylesheet and one HTML template per document type |
| `site/` | Not started. The production-company site that replaces the AI-ops one |
| `docs/` | Decisions specific to this repo |
| `archive/` | The AI-operations era: both versions of the old site and the two shipped products |

## Where the rest lives

- Document brand spec: `Lunar-Park-KB/relay/brand/document-brand.md`
- Template prose (intake, proposal, treatment, estimate, SOW, change order, invoice, control sheet, approval log, contract-path map, capability sheet, delivery record): `Lunar-Park-KB/relay/productions/templates/`
- Two-brand document system with the agency path: `Lunar-Park-KB/relay/document-system.md`
- Entity, formation, and business tracker: `Lunar-Park-KB/relay/productions/`
- Binder: `Lunar-Park/binder`
